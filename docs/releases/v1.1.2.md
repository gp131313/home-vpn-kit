**Исправлена установка OpenConnect: CLI 9.21 ставится отдельно.**

Что исправлено:
- Установщик OpenConnect-GUI 1.6.2 (win64) не содержит `openconnect.exe` и `vpnc-script-win.js` — на чистой машине установка 1.1.1 обрывалась с ошибкой «после установки нет …\openconnect.exe». Теперь набор дополнительно ставит OpenConnect 9.21 (CLI) из установщика проекта OpenConnect (артефакт GitLab CI тега v9.21, сверка SHA256) и копирует `openconnect.exe`, `vpnc-script-win.js` и `list-system-keys.exe` в папку OpenConnect-GUI. GUI по-прежнему даёт драйвер Wintun и окно для ручного подключения.
- Проверка версии (`openconnect --version`) выводится в журнал установки.

Обновление: запустить новый `HomeVpnKit-Setup.exe` поверх установленного набора; поле пароля можно оставить пустым — сохранённый пароль останется. Если `openconnect.exe` уже есть, CLI не скачивается.

Установка с нуля — как раньше: `HomeVpnKit-Setup.exe`, архив `home-vpn-kit-v1.1.2.zip` с `Install.cmd` или одной строкой `irm https://raw.githubusercontent.com/gp131313/home-vpn-kit/main/get.ps1 | iex`.

Установщики не подписаны: SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Контрольные суммы — в `SHA256SUMS.txt`.

С этой версии exe, архив и `SHA256SUMS.txt` собирает GitHub Actions (`windows-latest`) по тегу версии.

---

**English.** The OpenConnect-GUI 1.6.2 win64 installer does not ship `openconnect.exe` or `vpnc-script-win.js`, so a clean 1.1.1 install failed. The kit now also installs OpenConnect 9.21 (CLI) from the OpenConnect project's own Windows installer (GitLab CI artifact, SHA256-pinned) and copies the binaries into the GUI folder. To update, run the new `HomeVpnKit-Setup.exe` over the installed kit and leave the password empty to keep the saved one. The installers are not signed, so SmartScreen may warn: More info → Run anyway. Checksums are in `SHA256SUMS.txt`. Starting with this version the release is built by GitHub Actions.
