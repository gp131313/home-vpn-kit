**Кнопка «Только канал через HTTPS»: Telegram и Hermes без VPN.**

Что нового:
- На первой странице мастера появилась отдельная кнопка **«Только канал через HTTPS: Telegram и Hermes (без VPN)»**. Она не трогает VPN (OpenConnect, пароль, задачи сторожа) и настраивает только канал через WebSocket-дверь: Telegram получает SOCKS5 на `127.0.0.1:1080`, Hermes — SSH-алиас `hermes-http`.
- Компоненты канала (`hermes-http.ps1`, `telegram-tunnel.ps1`) установщик скачивает из папки, указанной в поле `KitUrl` в `config.json` рядом с exe или ключом `/kiturl=…`. Внутри — только исходящий 443, поэтому работает из мобильной сети, гостевого Wi-Fi и из-за границы, без входящих портов и без VPN.
- Скачанные `.ps1` пересохраняются в UTF-8 с BOM — Windows PowerShell 5.1 иначе читает их как ANSI и падает на кириллице; TLS принудительно 1.2 (.NET Framework по умолчанию 1.0 и получал «не удалось создать доверенную связь SSL/TLS»).
- Тихий режим для развёртывания: `HomeVpnKit-Setup-Silent.exe /tunnel /kiturl=https://…` — ставит только канал и возвращает код 0/1, журнал в `%LOCALAPPDATA%\HomeVpnKit\setup.log`.
- По завершении мастер печатает два ручных шага: в Telegram — «Продвинутые» → «Тип соединения» → SOCKS5 `127.0.0.1:1080`; в Hermes — «Шлюз» → «Подключение по SSH» → хост `hermes-http`.

Обновление: запустить новый `HomeVpnKit-Setup.exe` поверх установленного набора; поле пароля можно оставить пустым — сохранённый останется. Кнопка канала работает и без установленного VPN.

Установщики не подписаны: SmartScreen может предупредить — «Подробнее» → «Выполнить в любом случае». Контрольные суммы — в `SHA256SUMS.txt`.

---

**English.** The wizard now has a separate button **"HTTPS tunnel only: Telegram and Hermes (no VPN)"**. It leaves the VPN alone and sets up only the WebSocket door channel: Telegram gets SOCKS5 on `127.0.0.1:1080`, Hermes gets the `hermes-http` SSH alias. The channel components (`hermes-http.ps1`, `telegram-tunnel.ps1`) are downloaded from the folder given by `KitUrl` in `config.json` next to the exe or by `/kiturl=…`; only outgoing 443 is used, so it works on mobile networks and behind NAT. Downloaded scripts are re-saved as UTF-8 with BOM (Windows PowerShell 5.1 otherwise parses them as ANSI and fails on Cyrillic) and the downloader forces TLS 1.2. Silent mode: `HomeVpnKit-Setup-Silent.exe /tunnel /kiturl=https://…`. To update, run the new installer over the existing kit and leave the password empty. The installers are not signed, so SmartScreen may warn: More info → Run anyway. Checksums are in `SHA256SUMS.txt`.
